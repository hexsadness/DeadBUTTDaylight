# Contributing

Contributions are welcome.

## Good contribution areas

- Support for additional screen resolutions and HUD layouts
- More reliable action OCR
- Additional externally visible DBD events
- Better device reconnect handling
- Configuration/UI improvements
- Documentation and troubleshooting

## Ground rule

Keep detection external to the game. Do not add process-memory reading, DLL injection, game hooks, packet inspection, anti-cheat bypasses, or similar techniques.

## Development

1. Fork the repository.
2. Create a branch for your change.
3. Test the detector and device shutdown behavior.
4. Open a pull request describing the change and the resolution/HUD settings used for testing.
